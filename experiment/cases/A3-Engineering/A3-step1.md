
根据您提供的来源《What is an AI Agent? | Microsoft Copilot Studio》，作者和组织对 “Agent” 的要求和定义如下：

### 1. 明确要求的能力/属性

这些是来源在给出定义或解释其核心特征时明确提到的必要元素。

* **感知环境 (Perceive environment)：** Agent 必须能够获取其所在环境的信息。
  * *原文依据：* “An AI agent is an intelligent software system that **perceives its environment**...” (位置：AI agent definition)
* **做出决策与规划 (Make decisions & Planning)：** Agent 具备根据环境和目标选择方案的能力，并结合推理和规划来处理复杂任务。
  * *原文依据：* “...**makes decisions**, and takes actions to achieve specific goals.” (位置：Key takeaways; AI agent definition)
  * *原文依据：* “AI agents combine **reasoning, planning**, and adaptability to handle complex tasks...” (位置：AI agent definition)
* **执行行动 (Take actions)：** Agent 不仅仅是对话工具，它必须能在系统中执行实际操作。
  * *原文依据：* “...takes **actions** to achieve specific business goals.” (位置：What is an AI agent? 简介)
* **达成特定目标 (Achieve goals)：** Agent 的所有行为都是以结果为导向的，旨在完成预定义的任务或商业目标。
  * *原文依据：* “...takes actions to **achieve specific goals**.” (位置：AI agent definition)
* **适应性 (Adaptability)：** Agent 必须能够适应不断变化的目标或环境条件，而非仅仅遵循固定脚本。
  * *原文依据：* “...AI agents can execute complex, multi-step tasks and **adapt to changing goals**.” (位置：Key takeaways)
  * *原文依据：* “...AI agents can **adapt to new information** and adjust their actions accordingly.” (位置：AI agent definition 后的补充)
* **处理复杂、多步骤任务 (Handle complex, multi-step tasks)：** Agent 应当具备自动串联并执行多个步骤以完成复杂流程的能力。
  * *原文依据：* “Unlike chatbots... AI agents **plan and execute multi-step tasks** across systems.” (位置：AI agents vs. traditional automation)

### 2. 来源反复强调但未明确规定为必要条件的属性

这些属性在文中被多次提及，通常作为“负责任的部署”或“产生商业价值”的条件，但未包含在 Agent 的基础定义中。

* **人类监督与治理 (Human oversight & Governance)：** 来源多次提到为了“负责任地部署”，必须有人的参与和监管。
  * *原文依据：* “Responsible deployment requires **governance, transparency, and human oversight**...” (位置：Key takeaways)
* **产生商业价值 (Drive business value)：** 来源从商业角度出发，强调 Agent 应当能带来效率和可衡量的收益，但这更多是对“企业级 Agent”的期望。
  * *原文依据：* “AI agents drive **measurable business value** by delivering efficiency...” (位置：Key takeaways)
* **闭环反馈与持续改进 (Feedback loops & Continuous improvement)：** 来源描述了 Agent 的运作机理包含学习和改进，但未将其列为“成为 Agent”的入门门槛。
  * *原文依据：* “Feedback loops allow them to **adapt and improve over time**.” (位置：The mechanics of AI agents)

### 3. 只是实现方式，而非 Agent 概念本身的属性

这些是目前构建 Agent 所依赖的技术手段或架构组成，来源将其归类为“技术”或“组成部分”，而非定义本身。

* **语言模型 (Language models)：** 作为理解和推理的核心技术，但被视为“背后的关键技术”之一。
  * *原文依据：* “The **key technologies** behind AI agents include **language models**...” (位置：Key takeaways)
* **编排框架 (Orchestration frameworks)：** 用于协调工具和数据源的方法。
  * *原文依据：* “AI agents rely on several core technologies, including: ... **Orchestration frameworks**...” (位置：Key technologies)
* **API 与集成 (APIs and integrations)：** 用于访问企业系统的手段。
  * *原文依据：* “**APIs and integrations** for secure, real-time access to enterprise systems.” (位置：Key technologies)
* **特定的四部分架构 (4 key components)：** 来源提到 Agent 由感知模块、推理引擎、记忆系统和执行框架组成，这是其实现自动化和自主性的“机械结构（mechanics）”。
  * *原文依据：* “AI agents are **made up of four primary parts**, including: Perception modules, Reasoning engines, Memory systems, Execution frameworks.” (位置：4 key components)

### 4. 未明确或属于未来的属性

* **持久记忆 (Persistent memory)：** 来源明确将其列为“展望未来”的趋势，而非当前 Agent 的必要属性。
* **多智能体协作 (Multi-agent collaboration)：** 同样被列为“下一代企业自动化”的趋势。
* **完全脱离人类的自主权 (Total Autonomy)：** 虽然提到“自主执行（autonomously）”，但来源同时强调了“人类在环（Human-in-the-loop）”的重要性，因此并未明确要求 Agent 必须具备**完全脱离人类干预**的属性。
